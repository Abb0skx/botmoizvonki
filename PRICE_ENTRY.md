# Price Entry — переходный сайт ввода цен

URL: `https://bot.texnikach.uz/price/entry`. Ссылка «Ввод цен» добавлена
на страницу управления прайсом. Вход через существующий портал; права
`can_manage_prices`, проверка Origin и CSRF — без новых паролей.

## Источник данных

На переходном этапе **Google Price остаётся единым источником**. Сайт — второй
интерфейс к той же таблице, а не независимая копия. Это сохраняет действующий
импорт worker, сборку прайса, публикации и расписания. Google пока нельзя
отключать: следующий этап отказа от него потребует отдельной миграции worker.
`Price.py`, алгоритмы наценок и Product Sort не изменены.

Таблица задаётся `PRICE_ENTRY_SHEET_ID` (по умолчанию существующая Price).
Используются уже настроенные credentials `_google_client`. Секреты не попадают
в HTML, JS, Git или ошибки. Никаких новых прав сервисному аккаунту не выдаётся.

## Возможности

- 7 существующих поставщиков, модель/цвет/память/категория/ID;
- редактирование `price_1`, `price_12`, поиск и фильтры, страницы по 50 товаров;
- индивидуальные и массовые правки выбранных товаров;
- вставка одной/двух колонок цен из буфера по текущему порядку строк;
- предпросмотр до/после и явное сохранение; до 200 цен за операцию;
- целые USD 0…100000; пусто/0 — отсутствие предложения;
- история последних 100 операций сайта; полные записи остаются в SQLite;
- мобильные карточки и клавиатурный ввод (Enter — следующая цена).

Сайт не создаёт новые модели/ID и не переименовывает категории. Для текущего
каталога это отдельные операции вне ввода цен. Нажатие «Сохранить» обновляет
Price, но не отправляет Telegram-посты и не запускает импорт принудительно.
Обновление итогового прайса — по существующему расписанию worker.

## Безопасность и параллельные изменения

Перед записью перечитываются текущие ID, обе цены и описание товара.
Перемещение строки между загрузкой и сохранением разрешается по составному ID.
Смена версии строки вызывает 409 без записи всего пакета. Формулы, validation,
protected ranges и повреждённые ID блокируют соответствующие ценовые ячейки.
Сайт не пишет `min_price`, не меняет форматирование/формулы/структуру таблицы.
Один `spreadsheets.batchUpdate`, маска только `userEnteredValue`, точные ячейки.

Google Sheets не предоставляет compare-and-swap для ячеек: проверка защищает
от обнаруженных изменений до отправки, но НЕ является блокировкой редакторов
Google между чтением и записью. Не сортируйте и не редактируйте те же ячейки
в таблице во время сохранения сайта. Это ограничение переходного режима.
Сохранения самого сайта сериализованы файловой блокировкой.

До внешней записи фиксируется намерение в `price_entry_operations` внутри
основной SQLite (попадает в существующий backup). UUID/idempotency защищает
от повторной отправки того же запроса, в том числе после перезапуска.
При timeout или несовпадении readback — `uncertain`, повторная запись тем же
ключом запрещена. UI блокирует сохранение и просит сверить Google и обновить
данные. Автоматического отката Google нет: он мог бы затереть новую чужую цену.
История хранит предыдущие значения для осознанного восстановления через UI.
Актёр и correlation ID фиксируются существующим аудитом portal proxy.

## Развёртывание / откат

У production две части: самостоятельный price-server и portal из ветки
`codex/local-call-transcription-20260918`. В портал переносится только патч
price proxy, login-next и ссылки; остальные функции не меняются.
В price-server добавляются два Python-модуля, три статических файла и
регистрация роутов. Его текущий runtime не заменяется устаревшей копией main.

До обновления сохранить образ price-server и код. Собрать новый образ,
пересоздать только `web` (dispatcher/backup/worker без изменений). Проверить
healthz/readyz, отсутствие доступа к API без сессии, чтение всех поставщиков,
SQLite quick_check. Реальные цены для smoke-тестов не изменять.

Откат веба: вернуть старый образ на `texnikach-price-server:local`, восстановить
прежний router из release backup и `docker compose up -d --no-deps web`.
Дополнительные файлы и audit-таблица старому runtime не мешают; базу не удалять
и не откатывать целиком, чтобы не потерять новые задания/посты.
Portal: revert узкого коммита интеграции, дождаться одного webhook deployment.
Возврат старого кода не отменяет осознанно сохранённые пользователем цены.

Официальные контракты:
[UpdateCellsRequest](https://developers.google.com/workspace/sheets/api/reference/rest/v4/spreadsheets/request#UpdateCellsRequest),
[batchUpdate](https://developers.google.com/workspace/sheets/api/reference/rest/v4/spreadsheets/batchUpdate).
