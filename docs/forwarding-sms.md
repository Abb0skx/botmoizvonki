# Переадресация через Automate

`SMSForwardingService` использует существующие очередь SQLite, журнал,
права Telegram и ежедневный пост (20:00 Asia/Tashkent). Включение:
`FORWARDING_ENABLED=true`. Оба webhook-секрета обязательны.

Все команды отправляются через `calls.send_sms` с аккаунта Poco
`texnikach@gmail.com`. Клиентские SMS также всегда отправляются только с Poco;
выбор другого отправителя заблокирован, старые маршруты отправки не используются.
На Poco должна быть выбрана SIM +998901313999. API не выбирает SIM.
Получатели: Redmi +998908534466, Tecno +998908456162, Poco +998901313999.
Текст — строго `ON Poco`, `ON Redmi`, `ON Tecno` или `OFF`.
Poco на самого себя требует поддержки доставки SMS самому себе оператором.

Telegram: Abbos 202134293 — все телефоны; 7636344727 — Redmi;
702960146 — Tecno. Сайт использует существующую административную сессию
мониторинга с проверкой CSRF. Владельцы общего пароля сайта имеют полный
доступ: индивидуальные Telegram-ограничения к общей сессии неприменимы.

Принятие SMS сервисом НЕ означает доставку или успешную переадресацию.
Ответные входящие SMS на Poco от известных телефонов с маркерами Automate
сохраняются отдельно в `forwarding_sms_replies`, не попадают в оценки.
Ответ привязывается только при единственной отправленной команде за
предыдущие пять минут относительно времени SMS. Повторы webhook исключены.
Текст ответа показывается как есть (с безопасным экранированием), без
эвристического утверждения об успехе оператора. Формат не содержит ID
команды: ручные параллельные SMS-команды могут сделать корреляцию ненадёжной.
Поздние/неоднозначные ответы сохраняются без привязки. Отправленные SMS
никогда не являются ответом. Онлайн-копия в Google Sheets пока не опрашивается.

Автоповтора SMS нет, включая сетевые тайм-ауты и перезапуск при отправке.
Пауза — пять минут после последнего результата/запроса; незавершённая команда
также блокирует новую. Устаревшие MMI-команды из прежней очереди не отправляются.
Публикация пульта не отправляет SMS и не меняет переадресацию.

Проверка: `python3 -m unittest test_forwarding_sms test_forwarding_controls`.
